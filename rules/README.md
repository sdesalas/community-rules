# Elastic Community Rules

A small collection of detection rules for Elastic Security, contributed outside the prebuilt rules that ship with
Elastic. The rules cover Windows, Linux, macOS and AWS activity and are mapped to
[MITRE ATT&CK](https://attack.mitre.org/).

Each file holds one rule. Rules are grouped by platform in the `windows`, `linux`, `macos` and `cross-platform` folders,
and by data source under `integrations`.

The rules are sample content, written for demonstration. Review and test them before turning them on.
